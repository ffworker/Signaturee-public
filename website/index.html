02 / THE SOFTWARE

Two editions.
Different stages.

Windows

AVAILABLE

Self-hosted Outlook signature management,
with a browser-based workflow.

For IT
Employee lookup, group-assigned signatures, preflight, preview and individual generation. Targeted web runs support up to 50 AD users.
For employees
Authenticated self-service: generate and download your own assigned signatures, then follow the import instructions.
For your setup
Existing HTML/TXT templates and configurable attributes. Local output or an authorised SMB destination. A separate PowerShell bulk mode exists; it is not an unlimited verified web workflow.
Requirements & workflow limits +

Windows, PowerShell 5.1, Node.js 22.13+, LibreOffice and the RSAT ActiveDirectory module. AD read rights and domain connectivity are required. SMB rights belong to the backend task identity. Use HTTPS and protect the backend for remote access.

CSV/TXT worklists identify AD accounts; they do not replace directory attributes. Validate template encoding and HTML/RTF rendering with your own data.

Full prerequisites

Linux

IN DEVELOPMENT

Linux, in development.

An independent Docker-first implementation: offline test generation, LibreOffice conversion, CLI workflows and a limited development UI.

Real LDAP acceptance and the full authenticated Linux UI are still pending. No Windows feature parity is claimed; the backends and release lifecycles are separate.
