KNOW THE BOUNDARY

Built for Classic Outlook signature files. This is not native signature deployment for new Outlook or Outlook on the web.

01 / THE AVAILABLE EDITION

Windows, with a browser workflow.

For IT-managed generation and employee self-service, on infrastructure you control.

A

From directory to signature

Search employees in Active Directory, select their group-assigned signatures, then run preflight, preview and generation. Use existing HTML/TXT templates and configurable attribute mappings — not a built-in designer.

B

One person, or a targeted worklist

Generate for an individual or up to 50 selected AD users per web run. CSV/TXT worklists identify accounts to look up in AD; they do not replace directory data. A separate PowerShell bulk mode exists, outside the verified web workflow.

C

Let employees help themselves

Employees authenticate with AD credentials to generate and download their own assigned signatures, then follow the import instructions. Local Admin and IT roles remain separate from signature assignment.

What has been tested? The creator has personally used self-service from another device, generated assigned signatures and imported them as instructed. Automated checks cover code and packaging; neither is certification of a customer’s AD, SMB or Outlook installation. Validate your own templates, encoding and HTML/RTF rendering.

02 / AN INDEPENDENT EXPERIMENT

Linux, in development.

A separate, Docker-first implementation — not a repackaged Windows release.

Current development supports offline test generation, LibreOffice conversion, CLI workflows and a limited development UI. Real LDAP acceptance and the full authenticated Linux UI are still pending.

No Windows feature parity is claimed. The two editions have independent backends and release lifecycles.

Signaturee is an independently developed open-source project by Dennis Kappel, part of the Bytegeist ecosystem. It grew out of a practical IT problem: keeping employee signatures consistent without doing the same work over and over.

The aim is a useful tool, understandable code and honest limits. Try it, tell us what breaks, or help improve it.
