02 / THE SOFTWARE

Two editions.
Different stages.

Windows

AVAILABLE

Self-hosted Outlook signature management,
with a browser-based workflow.

For IT
Employee lookup, group-assigned signatures, preflight, preview and individual generation. Targeted web runs support up to 50 AD users.
For employees
With LDAP login, employees can regenerate their own assigned signatures on demand using current AD data. Directory access, group assignments and variable mappings must be configured correctly; download the result and follow the import instructions.
For your setup
Existing HTML/TXT templates and configurable attributes. Local output or an authorised SMB destination. A separate PowerShell bulk mode exists; it is not an unlimited verified web workflow.
Requirements & workflow limits +

Windows, PowerShell 5.1, Node.js 22.13+, LibreOffice and the RSAT ActiveDirectory module. AD read rights and domain connectivity are required. SMB rights belong to the backend task identity. Use HTTPS and protect the backend for remote access.

CSV/TXT worklists identify AD accounts; they do not replace directory attributes. Validate template encoding and HTML/RTF rendering with your own data.

Full prerequisites

Linux

IN DEVELOPMENT

Linux, in development.

An independent Docker-first implementation: offline test generation, LibreOffice conversion, CLI workflows and a limited development UI.

Real LDAP acceptance and the full authenticated Linux UI are still pending. No Windows feature parity is claimed; the backends and release lifecycles are separate.

Changelog & releases
  • A

    Install on Windows

    Start on a separate Windows test host with PowerShell 5.1, Node.js 22.13+, RSAT ActiveDirectory and LibreOffice. Extract the source ZIP into an empty folder, install dependencies and configure your directory and authentication. Test one local signature before SMB output; protect remote access with HTTPS.

    Full installation guide
  • B

    Bring your templates

    Supply a matching HTML + TXT pair and any image resources. Map placeholders such as $givenname and $department to directory fields, then assign signatures through existing AD groups. Signaturee does not create those groups. Check preview, encoding and logos before generating for employees.

    Template rules & variables
  • C

    Release with care

    Use a published release and verify its SHA-256 checksum. Green CI checks code and packaging, not your AD, SMB permissions or Outlook rendering. Qualify changes on a clean host, back up configuration, templates and state, and test upgrades side by side. Keep the previous version for rollback rather than overwriting a working install.

    Release & rollback checklist
